# Branch review, 2026-10-31 (codex/waleeds-library @ 4a19e1b)

Findings from a read-only review on Oct 31, 2026. Nothing here has been fixed yet. Ordered by severity.

## 1. Copyright exposure in the public bucket (high)

`GCS_LIBRARY_BUCKET=libxndr-library` is public-read and serves all 544 PDFs (416 works) copied from the Extreme SSD. Many of these are in-copyright works. Every entry in `library/catalog.json` is tagged `rights_status: curated_free_source`, but that tag was not checked per title. A DMCA or abuse complaint against public objects can put the whole GCP project at risk, not just the bucket.

Fix options: make the bucket private and serve through signed URLs (the app already supports `PDF_SIGNED_URL_TTL`), and audit each title's rights status, keeping only public-domain or openly licensed works public.

## 2. SSRF via redirects in the device API (high)

`GET /api/v1/eye/fetch` (`app/routes/device_api.py:308`) calls `_validate_public_url(url)` once on the URL it receives, then hands it to `_stream_pdf` (line 182). `_stream_pdf` builds an `httpx.AsyncClient(follow_redirects=True)`, so a public URL that redirects to `http://169.254.169.254/...` (the cloud metadata service) or another internal address is followed without being checked. The device source path at line 230 has the same pattern.

The Finder already does this correctly: `_download_limited` in `app/services/reading_desk.py:529` turns off automatic redirects and calls `_validate_public_url` on each hop. Fix: make `_stream_pdf` follow redirects manually using the same per-hop check. Also check `app/routes/reader.py:85`, which uses `follow_redirects=True` too.

## 3. Codex transcript committed into docs/README.md (medium)

`docs/README.md` is about 42,950 lines. After the documentation index (lines 1-47), a full Codex session transcript was appended, starting near line 48 ("# Inspect both library repos"). It includes local machine details: the list of installed apps, browser tabs, local URLs and session ids. Restore the index from before it was appended, and decide whether that content needs to be removed from git history.

## 4. Leftover duplicates and legacy code (low)

- `files/` holds stray copies of pipeline files (`config.py`, `config.yaml`, `llm.py`, `runner.py`, `s4_boundaries.py`) plus `taxonomy-pipeline-update.zip`.
- Two taxonomy agents (`app/agents/taxonomy.py`, `taxonomy_v2.py`), `admin/taxonomy_engine.py`, and `artifacts/*.v1.json` (193 books, each one "Full Text" chapter) predate the current product and aren't on the live path.

## 5. Router only considers 3 books (design limit)

`app/agents/reading_router.py:84` loops over `available_books[:3]`, and it scores by keyword overlap with section themes and summaries. The replacement is in `docs/KNOWLEDGE_GRAPH_DESIGN.md`. Related: all 544 catalog entries are `text_status: pending`, so no book text has been extracted for routing yet.
